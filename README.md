# ARIVA — Cinematic Sri Lanka Travel

Independent React + TypeScript + Vite project inspired by the ARIVA Cinematic V2 Figma storyboard.

## Local run

```bash
npm install
npm run dev
npm run build
```

## Features

- Four scroll-driven cinematic chapters with parallax layers and reduced-motion preference support
- 21 Sri Lankan destination collections, activities, hotels/stay suggestions, wellness options
- Silver, Gold, Platinum package presentations
- Custom tour builder with editable dates, destinations and activity selection, saved to local storage
- Browser locale and currency suggestions with user override
- Sample guide profiles and external review placeholders

## Important limitations

Some travel services listed are examples and require verification. Real pricing, currency conversion, translation catalogs, Google/Tripadvisor reviews and booking backend are **not** live. Inquiry email only opens a draft in the visitor's mail app. Scenic photographs loaded from Unsplash Source-style endpoints require valid stable hosted assets for production. Figma prototype: https://www.figma.com/design/m1GMvq83A8hv2xW0IPTXET?node-id=10-2

No code or assets were copied from the previous ariva-living-island repository.
